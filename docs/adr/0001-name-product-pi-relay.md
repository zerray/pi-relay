# Title

Name the product Pi Relay

# Status

Accepted

# Context

The repository was renamed from `pi-shell` to `pi-relay`. The app needs one product name for documentation, UI copy, package metadata, and platform packaging.

# Decision

Use **Pi Relay** as the product and app name.

# Consequences

User-facing copy, documentation, and future platform package names use Pi Relay. Older `pi-shell` references should be treated as historical names and removed when encountered.
